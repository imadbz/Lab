# Artifact Studio

A visual workflow builder for creating creative AI artifacts. Drag nodes onto a canvas, connect them, and compose AI-powered creative pipelines.

## Node Types

- **Inputs**: Text Input, Image URL
- **AI**: LLM Prompt, Image Generate
- **Transform**: Merge Text, Template
- **Outputs**: Preview, Markdown Renderer

## Getting Started

```bash
npm install
npm run dev
```
